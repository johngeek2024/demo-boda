# 🎭 Demo · Invitación de boda bilingüe (ES · 中文)

Demostración pública de una invitación de boda digital con panel de invitados.

- **Todos los datos son ficticios**: nombres, lugar, fecha, teléfonos y correos.
- **No hay servidor ni base de datos.** Lo que escribas se guarda solo en el `localStorage` de tu navegador y nunca sale de él.
- Panel de ejemplo: `/admin` (cualquier correo, contraseña `demo`).
- Sin música ni álbum de fotos en esta versión.

Hecho por [Jonathan Moreno](https://github.com/johngeek2024). El proyecto real es privado.
